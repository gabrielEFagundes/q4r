# Code of Conduct

The Quaoar project is a safe space for anyone to contribute, be it someone new to low-level or a senior.

The maintainer and contributors of the project will **not** accept disrespectful messages about one's nationality, race or sexual orientation. Please, be kind. Everyone in here is human and deserve to be welcomed!

## Issues and Pull Requests

Every issue and PR must make sense and follow a basic conduct, such as being polite and respectful to everyone participating on them.

If an issue or PR starts heating with people arguing, I will personally close them. If needed, you're welcome to open another issue/PR.

Spam will be ignored and automatically closed.

## Code

The code should preferrably not contain slurs, of course I won't be able to keep track of every single piece of code inside this repo (and I don't even want to, this project isn't just mine, it's from the community too), but people see the source code, and slurs/bad language wouldn't look that good on the project.

## Corrections

### PRs, issues or messages
Incase your message, issue or PR is poorly worded, either me or a contributor might edit it.

### Warnings
If you use too many slurs or write a message that's considered offensive to someone, the conduct bot might delete it, always with a reason.

### Lost of privileges
If you ever end up with elevated privileges over the repo (either by being a long time contributor or a maintainer) and use those privileges to spam, harass or do something to someone or the project itself, you will lose those privileges and may be banned from contributing to Quaoar.

Please mail me ([gabiehratfagundes@gmail.com](mailto:gabiehratfagundes@gmail.com)) if you believe someone is breaking the CoC, I'll review and take the needed action.
